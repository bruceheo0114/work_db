# 피알원 업무 허브

GitHub Pages에 배포된 기존 업무 도구를 한 화면에서 연결하는 팀 포털입니다.

## 연결된 도구

- 지출결의서 자동 생성기 (`Expense-Report`)
- KOL 단가·프로젝트 비용 DB (`campaign_cost`)
- KOL 계약서 관리 도구 (`Contract_Generator`)
- 일일·주차별 업무보고 생성기 (`work_report2`)
- Instagram·YouTube 소셜 지표 수집기 (`social-metrics-team`)

카드를 선택하면 포털 안의 통합 작업 영역에서 실행됩니다. 새 창 열기와 GitHub 원본 링크도 함께 제공합니다. 즐겨찾기는 사용자의 브라우저에만 저장됩니다.

## 배포

이 저장소의 `main` 브랜치를 GitHub Pages로 배포합니다.
